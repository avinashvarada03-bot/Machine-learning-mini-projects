# Machine-learning-mini-projects
Self-directed machine learning mini-projects including a simple neural network (NumPy), low-rank matrix compression (SVD), pruning, and quantisation examples. Built to strengthen understanding of linear algebra, tensors, and model-compression concepts.
# Machine Learning Mini-Projects (Self-Directed Learning, 2025)

This repository contains a collection of simple machine-learning mini-projects completed as part of my self-directed study to build foundational knowledge in neural networks, linear algebra, and model compression.

The goal of these exercises is to understand core mathematical concepts and basic implementations that support efficient deep-learning workflows, including tensor operations, low-rank approximations, pruning, and quantisation.

---

## Projects Included

### 1. Simple Neural Network (NumPy)
A basic neural network built from scratch using NumPy to learn XOR logic.

**Key concepts:**
- Matrix multiplication  
- Activation functions  
- Forward pass & backward pass  
- Gradient descent  

File: `simple_neural_network_numpy.py`

---

### 2. Low-Rank Matrix Compression (SVD)
Demonstrates dimensionality reduction using Singular Value Decomposition by reconstructing a matrix with fewer components.

**Key concepts:**
- Linear algebra  
- Tensor representation  
- Low-rank approximation  
- Reconstruction error  

File: `low_rank_compression.py`

---

### 3. Pruning & Quantisation Example
Explores basic model-compression concepts by removing low-magnitude weights and converting values to low-precision integers.

**Key concepts:**
- Weight pruning  
- Thresholding  
- Quantisation (int8)  
- Hardware-efficient optimisation  

File: `pruning_quantisation_example.py`
